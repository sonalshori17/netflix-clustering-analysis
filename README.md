# 🎬 Netflix Clustering Analysis

## 📌 Project Overview

This project applies Machine Learning clustering techniques to analyze Netflix's content library and discover meaningful patterns among movies and TV shows. The project includes data preprocessing, exploratory data analysis, feature engineering, clustering, and visualization.

---

## 🎯 Objective

The objective of this project is to group similar Netflix content using unsupervised machine learning techniques to uncover hidden trends and support data-driven decision-making.

---

## 📂 Dataset

The dataset includes:

- Title
- Type (Movie / TV Show)
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

---

---

## 🤖 Machine Learning Workflow

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Data Scaling
- K-Means Clustering
- Cluster Evaluation
- Data Visualization

---

## 📊 Key Insights

- Similar content was grouped into meaningful clusters.
- Clustering helped identify relationships among Netflix titles.
- The project demonstrates how unsupervised learning can reveal hidden patterns in entertainment datasets.
